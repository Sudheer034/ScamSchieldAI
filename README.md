# ScamShield AI

ScamShield AI is a static web application prototype focused on helping users identify potentially fraudulent job offers and learn safer job-search practices.

## Features

- **Job Offer Scanner**: Paste job text and detect common scam warning signs.
- **Risk Scoring**: Generates an illustrative risk score with warning level and recommendations.
- **Safety Guidance**: Highlights red flags such as upfront fees, credential requests, urgency pressure, and unrealistic pay claims.
- **Career Learning UI**: Includes sections for skills and verification-focused guidance.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript

## Project Structure

```text
ScamSchieldAI/
├── index.html    # Main application page
├── style.css     # Application styles
└── script.js     # Rule-based scam detection logic
```

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.

No build step or external runtime is required.

## Disclaimer

This project uses rule-based checks for awareness and educational purposes. Results are indicative and should not be treated as definitive fraud detection.
